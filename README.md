# flight-reservation-search-sort
A Python-based Flight Reservation System that demonstrates searching and sorting algorithms to manage flight records, search flights by destination, and sort available flights by price, departure time, or flight number.

# Flight Reservation System Using Searching and Sorting

## Project Information
- Subject: Data Structures
- Course: SPPU SE Computer Engineering
- Programming Language: Python
- Concepts: Linear Search and Bubble Sort

## Abstract
The Flight Reservation System is a Python-based mini
project that manages flight information using searching
and sorting algorithms.

The system stores flight numbers, source, destination,
ticket prices, departure times, and seat availability.
Linear Search is used to find flights by flight number,
while destination search helps users find suitable flights.
Bubble Sort arranges flight records by price, departure
time, or flight number.

The program also provides a basic seat reservation
feature and updates the available seat count.

## Objectives
- Implement searching and sorting algorithms.
- Search flights by flight number and destination.
- Sort flights by price, departure time, and flight number.
- Manage basic seat reservations.
- Understand practical applications of data structures.

## Data Structures Used
- List: Stores multiple flight records.
- Dictionary: Stores individual flight details.
- Linear Search: Finds a specific flight.
- Bubble Sort: Sorts flights using a selected field.

## Features
1. Display all flights.
2. Search by flight number.
3. Search by destination.
4. Sort by price.
5. Sort by departure time.
6. Sort by flight number.
7. Reserve a seat and update availability.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the folder in VS Code.
4. Run:

   python flight_reservation_system.py

## Complexity Analysis
Linear Search:
Time Complexity: O(n)

Bubble Sort:
Time Complexity: O(n^2)
Space Complexity: O(n) for the copied list.

Here, n represents the number of flight records.

## Applications
- Flight information management.
- Searching available flights.
- Comparing ticket prices.
- Basic reservation management.

## Limitations
- Uses sample flight data.
- Does not connect to a real airline database.
- Does not process online payments.
- Reservation data is not permanently saved.

## Conclusion
This project demonstrates how searching and sorting
algorithms can be applied to a flight reservation system.
It provides practical understanding of linear search,
bubble sort, lists, and dictionaries.
